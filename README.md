# University information system — Lab 10

UML modelling and Java reverse engineering of a university's scientific staff: faculties, institutes, employees, research projects and teaching assignments. Demonstration data are fictional.

## Run

Requires JDK 25 and Maven 3.9 or later.

```sh
mvn verify
java -cp target/classes edu.university.Application
```

Enter commands one per line. Project and course commands assign work to the demonstration employee `DEMO-002`; `show` displays the university and `stop` ends the session.

```text
project|Цифровой университет Ω|2026-01-01|2027-06-30|120
course|CS-010|UML-моделирование|4
show
stop
```
